# Sistema de gestión vehicular FES Aragón

- Mantener interfaz, comentarios y documentación en español.
- Usar TypeScript estricto, React, Express y SQLite local. Validar entradas con Zod.
- Mantener separadas la interfaz, las rutas HTTP y las reglas de negocio.
- No incorporar servicios externos obligatorios, Docker ni credenciales de proveedores.
- Comprobar `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build` y las pruebas de navegador pertinentes.
- Los datos de ejemplo deben ser ficticios y estar identificados como demostración.
